## Davinci Jr. 1.0 Hardware

Components that I was able to identify:

- 4x Stepper motors
- 1x Filament sensor
- 1x RFID reader
- 3x Optical endstops
- 1x Top light bar

I only identified the ones that need to be defined in the firmware.
